# React Support Dashboard

Painel de chamados de suporte construído com React e Vite. Os dados são demonstrativos e ficam no estado da aplicação durante a sessão.

## Funcionalidades
- Resumo de chamados abertos, em andamento e resolvidos.
- Busca textual e filtro por status.
- Cadastro de chamado por formulário.
- Alteração do status diretamente na lista.
- Componentes funcionais e hooks (`useState`, `useMemo`).

## Executar
Requer Node.js 18 ou superior.
```bash
npm install
npm run dev
```
Acesse o endereço local apresentado pelo Vite.
